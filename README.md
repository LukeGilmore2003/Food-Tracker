# Food Tracker

A food tracking app that helps households reduce waste by tracking items and their expiration dates.

## About the Project

Lots of food gets thrown away because people forget what they have or don't notice it's about to expire. This app lets users enter items in their fridge or pantry along with expiration dates, then displays them sorted by what expires soonest, with color coding to highlight items that need to be used quickly.

Planned features include reminder notifications, food categories, and a shared list for roommates or families. Recipe suggestions based on expiring ingredients are a stretch goal.

## Development Process

This project is being developed using Scrum, with work organized into sprints.
